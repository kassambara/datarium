# datarium hex logo

Source for the package hex sticker shipped at `man/figures/logo.png`.

- `datarium_hex.svg` — the vector master. Rasterise to PNG with `rsvg` (or any SVG
  renderer); `man/figures/logo.png` is the 240 px export.

Design: a normal-density curve with the observations drawn on it (one data set per
test), on the Datanovia blue-charcoal ground. datarium takes the **biostatistics**
pillar tint, teal `#14a097` (lightening to `#3fd0c3`), with a single amber `#f5a524`
accent. Wordmark set in **Bricolage Grotesque** (SIL Open Font License). To reproduce
the wordmark exactly, that font must be available to the renderer.
